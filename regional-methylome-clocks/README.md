# Региональные представления метилома для эпигенетических часов мыши

Два воспроизводимых пайплайна для Google Colab на открытых данных RRBS (бисульфитного секвенирования сокращённого представления генома) крови мыши, сборка mm10. Оба отвечают на один вопрос: какое представление метилома — отдельные CpG, регионы или модель состояния региона — даёт точные и переносимые между когортами часы возраста.

- **Пайплайн 1** (базовый). Сравнивает отдельные CpG, регионы DBSCAN, окна 5 кб (по RegBC), сегменты оригинального MethyLasso, регионы ChromHMM и их пересечения. Проверяет описания внутреннего паттерна региона, графовую регуляризацию по контактам Hi-C и устойчивость к деградации данных.
- **Пайплайн 2** (исследовательский). Строит регионы согласованного возрастного изменения и измерительную модель региона: сдвиг \(\hat u\) и несогласованность \(D\) с учётом покрытия. Дополнительно проверяет пространственные модули Hi-C с контролем по случайным парам на том же расстоянии и надёжность оценок при смене набора CpG.

Подробное описание того, что сделано, что получилось и как это связано с исходным планом, — в [REPORT_ru.md](REPORT_ru.md).

## Запуск в Google Colab

1. Откройте блокнот из `notebooks/`. Можно открыть прямо с GitHub: `https://colab.research.google.com/github/<пользователь>/<репозиторий>/blob/main/notebooks/01_regional_clocks_real_data.ipynb`. Можно и загрузить файл через «Файл» → «Загрузить блокнот».
2. Достаточно стандартной CPU-среды (около 12 ГБ ОЗУ). Нужно около 15 ГБ свободного диска; GPU не нужен.
3. Выберите «Среда выполнения» → «Выполнить все». Блокнот сам установит зависимости, скачает данные, выполнит эксперименты и предложит скачать ZIP с результатами.
4. Чтобы при повторных запусках данные не скачивались заново, включите в первой ячейке `USE_DRIVE = True`: рабочий каталог переедет на Google Drive. Если оба блокнота используют общий `WORK`, пайплайн 2 переиспользует данные и матрицу пайплайна 1.

Ориентировочное время: пайплайн 1 — 1,5–2 ч, пайплайн 2 — около 1 ч; при общем `WORK` загрузка данных не повторяется. Больше всего времени занимают загрузка архива GSE120136 и LASSO по ~10⁶ CpG. Локальный запуск вне Colab тоже возможен: задайте переменные окружения `REGCLOCK_WORK` и `REGCLOCK_DATA`.

## Протокол

Разбиение: 111 train, 30 внутренний тест (стратификация по децилям возраста, seed 20261014), 20 CR, 50 внешний C57BL/6J, 22 внешний BALB/c. На train оцениваются словарь CpG (покрытие ≥ 5 у ≥ 50 % train), все разбиения на регионы, импутация, стандартизация, возрастные наклоны, сегментация и референсные профили. Затем всё фиксируется и применяется к тестовым когортам без подстройки по их ответам. Модель для всех представлений одна — LassoCV с 5-кратной кросс-валидацией внутри train. Метрики: MAE (средняя абсолютная ошибка, мес.) с 95 % бутстреп-интервалами и парные бутстреп-разности ΔMAE на одних и тех же животных.

## Главные результаты (внешний тест C57BL/6J, MAE, мес.)

| Представление | MAE |
|---|---|
| Отдельные CpG (1 051 899 признаков) | 2,71 |
| Регионы DBSCAN, среднее | 2,14 |
| Окна 5 кб, среднее | 1,82 |
| DBSCAN ∩ ChromHMM, среднее | 1,93 |
| MethyLasso, среднее | 2,26 |
| Регионы согласованного изменения, среднее (пайплайн 2) | 2,01 |
| Регионы согласованного изменения, сдвиг + несогласованность | 3,01 |

Регионализация переносится лучше отдельных CpG и намного устойчивее к потере CpG. Внутрирегионный паттерн ухудшает перенос. Контакты Hi-C не дают пользы сверх рандомизированного графа. Сдвиг надёжнее среднего при смене набора CpG, но как признак часов уступает ему. На BALB/c лучше всего работают отдельные CpG и MethyLasso. Подробности и ограничения — в [REPORT_ru.md](REPORT_ru.md).

## Ограничения

Выборки небольшие, используется один фиксированный сплит. Внешние когорты получены в той же лаборатории обработки. Hi-C и ChromHMM — референсы не из крови. Клеточный состав и batch-эффект не скорректированы. Пайплайн 2 — проверка исследовательской гипотезы, а не опубликованный метод с доказанной новизной.

## Лицензии сторонних компонентов

Репозиторий не содержит кода MethyLasso: блокнот клонирует его во время запуска (лицензия — в репозитории авторов). Данные GEO, 4DN и ChromHMM скачиваются из первоисточников и в репозиторий не включены.
